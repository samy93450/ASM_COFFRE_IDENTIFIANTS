# ASM Coffre Identifiants

Application web/PWA personnelle pour organiser des fiches d'identifiants.

## GitHub Pages

1. Publier tous les fichiers de ce dossier à la racine de la branche `main`.
2. Ouvrir **Settings > Pages** dans le dépôt GitHub.
3. Choisir **Deploy from a branch**.
4. Sélectionner **main** et **/(root)**, puis enregistrer.

Le point d'entrée est `index.html`.

> Pour des identifiants sensibles, privilégiez un gestionnaire de mots de passe chiffré plutôt qu'un site public. Vérifiez que l'application ne contient aucune donnée personnelle avant de publier le dépôt.


Optimisation GitHub : les images sont stockées comme fichiers séparés afin de garder index.html sous 288 KB.
